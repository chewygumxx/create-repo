# Implementation Plan: Bun

> [!IMPORTANT]
> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bun replaces npm as the package manager and Node as the runtime in
`create-repo`, in its npm family of templates (renamed the bun family), and
in the shared workflows of `chewygumxx/.github`, with npm kept only to
publish.

**Architecture:** Each Bun repository carries `bunfig.toml` with
`[run] bun = true`, so every `bun run` script, nested ones included, runs
its `#!/usr/bin/env node` CLIs on Bun even when a Node is on `PATH`.
`bun.lock` replaces `package-lock.json`; the `bunLock` identity edit sets
its `workspaces[""].name` through `jsonc-parser`. The `npm` layer becomes
`bun`, `FAMILIES.npm` becomes `FAMILIES.bun`, and the shared `lint.yaml`
and `commitlint.yaml` pick bun or npm from the caller's lockfile.

**Tech Stack:** Bun 1.4 (`bun install`, `bun run`, `bun test`, `bunx`),
`@types/bun` 1.4, jsonc-parser 3, mise, GitHub Actions; npm 11 (from Node
24) for `npm stage publish` and `npm pack` only.

**Spec:**
[`docs/specs/2026-10-02-bun-design.md`](../specs/2026-10-02-bun-design.md)

## Global Constraints

- mise pins `bun = "1.4"`; `package.json` declares
  `"engines": { "bun": ">=1.4" }`; `@types/bun` is `^1.4.2`.
- Every bun family layer set, and this repository, has `bunfig.toml` with
  `[run]` and `bun = true`.
- No `package-lock.json` remains in this repository or under `templates/`.
- Setup is `bun install --frozen-lockfile`, format
  `bun run --silent format`, check `bun run check`.
- Hooks call `bunx --bun --no-install <tool>`; `npx` appears nowhere.
- npm runs only as `npm stage publish` in a publish workflow and as
  `npm pack` in `test/pack.test.js`. This repository keeps `node = "24"` in
  `mise.toml` for npm; a template's publish workflow runs
  `mise exec node@24 -- npm stage publish`.
- The CLI is invoked as `bun create @chewygumxx/repo [name] [flags]`, with no
  `--`: `bun create` passes flags through, and passes a `--` through too.
- This repository's tests stay on `node:test`; its test script is
  `bun test ./test/`, never a bare `bun test` (that also runs the test files
  `lint:templates` materialises under `.templates/`).
- Templates keep `chewygumxx/repo-tmpl` in their headers and identity.
- No em dash (U+2014) anywhere. Commit titles are sentence case and at most
  50 characters.
- The version stays 2.1.1: the 3.0.0 bump and the release are out of scope.

## Review Focus

1. **A Node on `PATH`, as on every GitHub runner.** A bun family script must
   still run on Bun. Task 3 asserts each bun family combination composes a
   `bunfig.toml` with `bun = true`, and Task 10 runs the checks with Bun's
   own `node` only.
2. **The old `npm create … -- name --flags` form, retyped for Bun.**
   `bun create` passes the `--` through and `parseArgs` then reads every flag
   as a positional, failing with "Expected one repository name". Task 2 drops
   one leading `--`, with a test.
3. **A bare `bun test`** picks up `.templates/**/*.test.ts` after
   `lint:templates`. Task 1 pins the script to `bun test ./test/`.
4. **A caller of the shared workflows holding both lockfiles, or neither.**
   Either fails with an error naming both files, rather than guessing. Task 9
   verifies the three cases of its detect step by hand, since that
   repository has no test runner for workflow shell.
5. **npm creeping back into a run.** Task 2 keeps an `npm` stand-in on
   `PATH` in `test/bin.test.js` and asserts no bun family dry run calls npm or
   node.

/**
 * Sets keys of a JSONC file with jsonc-parser, keeping its comments, its
 * trailing commas and its layout. A key is a top-level key or a path to a
 * nested one; a value of `undefined` removes it.
 * @param {string} path
 * @param {string} name names the file in errors
 * @param {[string | string[], unknown][]} changes
 */
function editJsonc(path, name, changes) {
    let text = readFileSync(path, "utf8");
    /** @type {import("jsonc-parser").ParseError[]} */
    const errors = [];
    const data = parse(text, errors, { allowTrailingComma: true });
    if (errors.length) {
        fail(
            `${name}: ${errors.map((e) => printParseErrorCode(e.error)).join(", ")}`,
        );
    }
    for (const [key, value] of changes) {
        const keys = typeof key === "string" ? [key] : key;
        /** @type {any} */
        let node = data;
        for (const part of keys) {
            if (node === null || typeof node !== "object" || !(part in node)) {
                fail(
                    `"${keys.map((k) => k || '""').join(".")}" in ${name} not found`,
                );
            }
            node = node[part];
        }
        const edits = modify(text, keys, value, {
            formattingOptions: { insertSpaces: true, tabSize: 4 },
        });
        text = applyEdits(text, edits);
    }
    writeFileSync(path, text);
}
